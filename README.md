# Vedda Studio — sourcing scanner

A scanner that watches Swedish/Danish auction sites (Auctionet, Tradera,
Bukowskis, Haraldssons) for undervalued mid-century seating, plus a manual
search checklist for Facebook Marketplace (can't be automated — Meta's ToS
bans it).

Results: **[live scan results →](https://<username>.github.io/<repo>/)**

This is the sourcing tool only. It does not include supplier pricing, piece
costings, or buy strategy — those stay private.
